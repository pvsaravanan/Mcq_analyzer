# Low-token checklist

- Ask for the URL only if missing.
- Do not ask practice/graded/proctored status.
- Use one focused accessibility read per question/page.
- Never dump the full DOM or repeat unchanged page text.
- No per-question narration or explanations.
- Reuse extracted question/options; do not re-read.
- Prefer text/accessibility over screenshots.
- No arbitrary delays; one minimal check after navigation.
- Keep only compact progress counters.
- Pause on ambiguity.
- Confirm once before irreversible final submission.
